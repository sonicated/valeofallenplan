# Repository Instructions

- Do not deploy, publish, release, or upload this site unless the user explicitly requests it in the current message.
- Do not run `npm run deploy`, `wrangler pages deploy`, `git push`, `gh repo create`, or any equivalent remote-changing command without that explicit instruction.
- Treat requests to edit, build, preview, or test as local-only. Permission granted in an earlier message does not carry forward to later work.
